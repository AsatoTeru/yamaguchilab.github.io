# デバイスマテリアルズ研究室 Webサイト試作

このフォルダの `index.html` をChromeで開くとローカルでプレビューできます。

## ファイル
- `index.html`: ページ本文・メニュー・研究紹介・お知らせなど
- `style.css`: 色、フォント、カード、スマホ対応の見た目
- `script.js`: スマホメニューの開閉

## GitHub Pagesで公開する
1. GitHubでアカウント（または研究室用Organization）を作る。
2. `ユーザー名.github.io` という名前の**Public**リポジトリを作る。
3. このフォルダ内の3ファイルをリポジトリのルートにアップロードしてコミットする。
4. Settings → Pages → Build and deployment → Source: Deploy from a branch を選ぶ。
5. Branch `main` / `(root)` を指定して Save。公開URLは `https://ユーザー名.github.io/`。

## 公開前の確認事項
- 大学・研究室の正式名称や説明、連絡先を責任者に確認。
- 研究テーマの説明は試作用なので実態に合わせて修正。
- ニュースの例、YYYY.MM、準備中表記を修正。
- 学生の顔写真や氏名の公開は本人の了承を得る。
- 大学公式サイトと誤認されないよう、公式ロゴ利用ルール等を確認。
- 公開リポジトリに個人情報・未公表研究データ・パスワードを置かない。

## 更新
`index.html` の文章を書き換え、GitHubの `Commit changes` で更新します。
